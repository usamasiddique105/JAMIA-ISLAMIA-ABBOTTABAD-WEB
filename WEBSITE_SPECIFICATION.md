## 2. Key Interactive Features & Modals
- **Fatwa Detail Modal**: Displays Fatwa ID, Question, Authoritative Scholarly Answer, Quran/Hadith references, Mufti signature seal, copy link button, print/download PDF button.
- **Fatwa Submission Form**: Name, Phone/WhatsApp, Email, Country/City, Fatwa Category (Worship, Transactions, Marriage/Divorce, Inheritance, Contemporary Issues), and Detailed Question text box.
- **Exam Search Engine**: Input Roll Number, Select Academic Year, Select Class (Dars-e-Nizami, Takhassus, Hifz, Tajweed) -> Instantly generates verifiable digital marksheets.
- **Global Search Modal**: Keyboard accessible modal searching across Fatwas, News, Library Books, and Departments in real time.
